# Daily RNG games (hub)

The landing page at https://sharkjujg.github.io/ linking ten daily roll-and-collect games: BookRNG, CinemaRNG, ExoRNG, QuakeRNG, PeakRNG, AsteroidRNG, BrickRNG, SpeciesRNG, AirportRNG and CityRNG. Each lives in its own repository and project page (`/<name>/`); this repository is a single static `index.html` with no build step.

The counts on the cards (pool sizes, achievements) are copied from each game's pages when this was written; update them if a game's pool changes.
