Daily RNG games

Roll once a day, discover one random item, and find out what makes it unusual. Every item has the same chance, rarer properties earn more points, and each game has hundreds of achievements that scale with its pool. Every game uses real data.

How they work

Each game draws one item per UTC day from a fixed pool, using a secure random number with no bias toward any item. Badges are plain rules counted across the pool, and a badge's value is 100 divided by the share of the pool that has it. Results stay in your browser: there are no accounts, no tracking and no server, so leaderboards and friends are not built.
